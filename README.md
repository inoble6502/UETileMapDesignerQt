# UETileMapDesignerQt

Application designed and programmed in Qt Creator and C++. Purpose is to draw and generate map data to be used in https://github.com/inoble6502/TileGenCPP (and its Blueprint Script counterpart) where it would be represented and traversable in 3D. This program allows for the customization of individual tile data. 

A prototype version was made here: https://github.com/inoble6502/BasicDungeonLayoutMaker
